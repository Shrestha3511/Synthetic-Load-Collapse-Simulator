# SLCS — Synthetic Load Collapse Simulator

> **The crash-test dummy for the AI-Agent era.**

A real-time visual simulator that models how AI agent swarms cause
"Cognitive DDoS" attacks on human hiring pipelines — and lets you
test defenses before your system collapses.

## Live Demo
[Click here to run SLCS in your browser](https://shrestha3511.github.io/Synthetic-Load-Collapse-Simulator/slcs.html)

## What it does
In 2026, an AI agent can generate 10,000 hyper-personalized resumes
in 5 minutes at zero cost. Traditional firewalls can't stop them —
the server stays up (HTTP 200 OK), but the human HR department
suffocates under semantic overload.

SLCS simulates this attack using real queue theory math (Little's Law)
and lets system architects test defenses interactively.

## Features
- Live particle funnel — cyan = humans, red = AI bots
- HR Burnout Meter with cognitive load tracking
- Time-to-Collapse calculator (Little's Law: L = λ/μ)
- 5 interactive defenses: Turing Trap, Semantic Dedup, Micro-Friction Fee, Behavioral CAPTCHA, IP Rate Limiting
- Quick scenarios: Calm Market, Cognitive DDoS, Bot Wave, Full Defense
- Snapshot report export
